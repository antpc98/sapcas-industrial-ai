# Reglas de negocio MVP — Supply Chain Intelligence v1

Este documento define semántica funcional, trazable y explicable para el primer dominio de SAPCAS: **Supply Chain Intelligence v1**. No afirma que existan servicios, endpoints o interfaz implementados. Toda regla que depende de fechas recibe una `reference_date` explícita; los ejemplos demo usan `2026-09-03`.

La evidencia actual es **SAPCAS Synthetic Demo**: permite verificar trazabilidad, consistencia y comportamiento, pero no valida umbrales para una empresa industrial real. Su madurez prevista es: Definición de regla → Demo sintética SAPCAS → Dataset industrial público → Piloto → Datos de cliente → Regla de producción calibrada.

## Convenciones comunes

- La reconciliación monetaria/cuantitativa admite tolerancia `0.011`, pues el CSV está redondeado a dos decimales.
- El demo actual usa EUR. Una comparación entre monedas requiere una política explícita de tipo de cambio, fecha y fuente; mientras no exista, el resultado es `NOT_CALCULABLE`.
- `source_*` / `SOURCE / PROVIDED DATA` identifica un valor aportado por la fuente. `calculated_*` identifica una métrica derivada por SAPCAS. No son equivalentes.
- Estados de disponibilidad: `NOT_AVAILABLE` (no existe el campo o relación), `INSUFFICIENT_DATA` (existe pero no cumple cobertura mínima) y `NOT_CALCULABLE` (la fórmula no puede ejecutarse con entradas válidas).
- Los estados READY/PARTIAL describen definición y evidencia de la regla, no implementación de producto.

## Patrón común de alertas

Las reglas pueden emitir `INFO`, `LOW`, `MEDIUM`, `HIGH` o `CRITICAL`. Es un vocabulario transversal; no convierte porcentajes aislados en una verdad industrial. La severidad futura deberá combinar desviación relativa, impacto económico absoluto, criticidad, urgencia y contexto operacional cuando existan datos.

La única configuración inicial explícita es para PROC-002: una subida de precio de **+10 %** dispara una alerta `MEDIUM` de demo/MVP. Es configurable y pendiente de calibración con cliente. Una caída de precio puede mostrarse como `INFO` u oportunidad, no como riesgo. Ninguna otra regla inventa rangos de severidad.

## Evolución y límites de datasets externos

No se integra ningún dataset externo en Supply Chain v1. El demo SAPCAS permanece bajo control del producto para Inventory, Procurement, Supplier, RFQ, reglas deterministas y demostraciones end-to-end. La estrategia de laboratorios está en [08_LABS.md](08_LABS.md).

En una futura trazabilidad entre dominios, la cadena conceptual puede ser `Activo → Fallo → Componente → Material → Lote/recepción → Compra → Proveedor`. Permite investigar asociaciones entre calidad, suministro y operación; una correlación nunca prueba causalidad y SAPCAS deberá expresar nivel de evidencia.
