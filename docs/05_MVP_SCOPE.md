# Alcance del MVP — Supply Chain Intelligence v1

El MVP debe demostrar que datos industriales se convierten en decisiones económicas medibles y explicables.

| Área | Resultado esperado | Estado |
| --- | --- | --- |
| Inventory Intelligence | Cobertura, faltante, exceso, baja rotación y valor. | Planificado; datos base cargados. |
| Procurement Intelligence | Precio, variación, coste y entrega. | Planificado; pedidos cargados. |
| Supplier / RFQ | Candidatos fundamentados para solicitar oferta. | Planificado; fuentes necesarias aún no cargadas. |

Incluye datos demo, PostgreSQL, API, reglas simples/trazables y evolución de alertas a recomendaciones. Las reglas funcionales están definidas; su ejecución en producto es posterior. Excluye ERP completo, Maintenance/Production/Operational Intelligence, energía, planificación, visión artificial, trading, integraciones no justificadas y Redis/Kafka/Kubernetes/Terraform/LangChain como núcleo del MVP.
