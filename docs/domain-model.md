# Domain Model v0.1

Entidades previstas para el primer ciclo:

- Company
- Material
- Supplier
- InventoryItem
- Purchase
- Quote
- Opportunity
- AgentRun

## Principio arquitectónico

Los cálculos objetivos deben realizarse mediante reglas, SQL y Python.

El LLM se utilizará para:

- explicar,
- resumir,
- contextualizar,
- generar recomendaciones legibles.

El LLM no será la fuente de verdad para stock, costes, scoring o ahorro.
