# SAPCAS Sevilla Metal/Aero Dataset v0.1

Dataset sintético para el desarrollo inicial de SAPCAS Industrial AI.

## Tamaño
- Companies: 1
- Plants: 1
- Warehouses: 3
- Materials: 35
- Suppliers: 12
- Supplier-material relationships: 71
- Filas de inventario: 35
- Purchase requisitions: 31
- Purchase order lines: 260
- Goods receipts: 255
- Controlled scenarios: 10

## Uso recomendado
Primero implementar Inventory Intelligence.
Después RFQ y Procurement sobre este mismo modelo.

No ampliar el dataset salvo que un test, una demo o un cliente justifique el cambio.
